Research Interests

Software Engineering · Software Security · AI for Software Engineering (AI4SE) · AI/LLM Security and Privacy · Software Architecture

Software Engineering and AI4SE

My research interests include applying AI to software engineering challenges such as software testing, code analysis, bug detection, program understanding, automated code generation and repair, and intelligent developer tools. I am particularly interested in how large language models (LLMs) and other AI techniques can improve software development while maintaining correctness, reliability, and software quality.

I am also interested in software architecture, maintainability, and engineering methods for building reliable, scalable software systems.

Software Security and Vulnerability Analysis

I am interested in understanding how vulnerabilities arise in software systems, how they can be systematically discovered, and how effective defenses can be developed. Areas I would like to explore include vulnerability detection, static and dynamic program analysis, security testing, authentication and authorization security, and automated security analysis.

I am particularly interested in the intersection of software engineering and cybersecurity, including the use of AI-assisted techniques to identify vulnerabilities and improve software security.

AI/LLM Security and Privacy

Another research direction I am interested in exploring is the security and privacy of AI-enabled systems, including vulnerabilities in large language models, adversarial attacks, backdoor attacks, and security risks introduced when AI components are integrated into software applications.

I am also interested in security challenges in emerging computing platforms and the development of techniques to evaluate and improve the security and reliability of AI-driven systems.

Background and Research Transition

My academic research background is in Computer Vision and Machine Learning, where I worked on iris recognition, image processing, segmentation, deep learning, and medical image analysis.

My subsequent professional experience as a Software Engineer in the banking sector has involved enterprise application development, software architecture, authentication and authorization, access control, data integrity, and production system reliability.

These experiences have motivated my transition toward research in Software Engineering and Software Security, particularly where software analysis, AI-assisted development, vulnerability discovery, and secure AI systems intersect.
