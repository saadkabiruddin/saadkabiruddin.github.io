Within Software Engineering, I would like to explore AI-assisted software testing, bug detection, fault localization, program analysis and repair, and code understanding, including LLMs for Software Engineering and intelligent developer tools.

Software Engineering for AI (SE4AI) and Software Architecture

Software Security and AI for Security

I am interested in secure software engineering and applying AI to vulnerability detection, secure-code analysis, and software security testing, including LLM-assisted vulnerability analysis. Computer Vision / Machine Learning

This work and my ML projects provide a foundation for my intended research direction.
