Research Interests

My research interests span software engineering, software security, and AI/LLM security and privacy. I am particularly interested in software testing, vulnerability analysis, AI-assisted software development, and improving the security and reliability of AI-enabled systems. I am also exploring software engineering challenges in cyber-physical and autonomous systems, particularly UAVs, with an emphasis on safety, security, and dependable operation.

Software Security · AI/LLM Security and Privacy · Cyber-Physical Systems (CPS) · Software Engineering · AI for Software Engineering (AI4SE)

Software Security and Vulnerability Analysis

My primary research interest is understanding how vulnerabilities arise in software systems and developing techniques to identify, analyze, and mitigate them. I am particularly interested in static and dynamic program analysis, vulnerability detection, security testing, authentication and authorization security, and automated security analysis.

AI/LLM Security and Privacy

I am interested in investigating security and privacy vulnerabilities in AI-enabled systems, particularly large language models. My interests include adversarial attacks, backdoor attacks, prompt injection, and developing techniques to evaluate and improve the security, privacy, and trustworthiness of AI-driven applications.

Cyber-Physical and Autonomous Systems

I am developing a research interest in cyber-physical systems, particularly UAVs and autonomous systems. I am interested in software safety, runtime monitoring, fault detection, real-time systems security, and the application of AI techniques to improve the reliability and security of autonomous operations.

Software Engineering and AI4SE

My interests also include software testing, program analysis, software architecture, and AI-assisted software development. I am particularly interested in using machine learning and large language models for automated code analysis, bug detection, program comprehension, and software repair while maintaining software quality and reliability.
